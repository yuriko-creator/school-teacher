1. Вспоминаем знакомое

Прежде чем говорить о клавиатуре, вспомним несколько важных понятий.

  • Информация — сведения об окружающем мире и различных объектах.
  • Виды информации — текстовая, числовая, графическая, звуковая и другие.
  • Устройства компьютера — части компьютера, предназначенные для выполнения определённых задач.
  • Устройства ввода — устройства, с помощью которых информация поступает в компьютер.

2. Что такое ввод информации?

Ввод информации — это передача данных от пользователя или другого источника в компьютер.

Например, когда мы набираем текст на клавиатуре, компьютер получает введённые нами буквы. Когда говорим в микрофон — компьютер получает звук.

3. Ввод и хранение — это не одно и то же

📥 Ввод

Информация поступает в компьютер.

Например: мы нажимаем клавишу А, и компьютер получает этот символ.

💾 Хранение

Информация сохраняется в памяти компьютера, чтобы её можно было использовать позже.

Например: сохранение созданного документа.

Пользователь → устройство ввода → компьютер → память

4. Клавиатура

Клавиатура — устройство ввода информации, предназначенное прежде всего для ввода текста, чисел и различных символов.

С помощью клавиатуры можно вводить:

  • буквы;
  • цифры;
  • знаки препинания;
  • специальные символы;
  • команды и сочетания клавиш.
Клавиатура. Изображение: Joe lope / Wikimedia Commons , CC BY-SA 4.0.

5. Основные группы клавиш

1

Буквенно-цифровые

Используются для ввода букв, цифр, знаков и символов.

А Б В Г Д 1 2 3
2

Функциональные

Выполняют специальные функции в программах. Обычно обозначаются клавишами F1–F12.

F1 F2 F3 F4 F5 F6
3

Клавиши управления

Используются для выполнения команд и управления работой программ.

Ctrl Alt Shift Enter Esc
4

Клавиши перемещения

Позволяют перемещать курсор или переходить по содержимому документа.

↑ ↓ ← →
5

Цифровой блок

Предназначен для удобного ввода чисел и выполнения некоторых арифметических действий.

7 8 9 4 5 6 1 2 3 0

7. Основные клавиши

Space Пробел

Создаёт промежуток между словами.

Enter Переход на новую строку

Также может использоваться для подтверждения действия.

Backspace Удаление слева

Удаляет символ, расположенный слева от курсора.

Delete Удаление справа

Удаляет символ справа от курсора или выбранный объект.

Shift Заглавные буквы

Используется для ввода заглавных букв и верхних символов клавиш.

Caps Lock Режим заглавных букв

Переключает режим постоянного ввода заглавных букв.

↑ ↓ ← → Перемещение

Перемещают курсор по тексту.

Ctrl + ... / Alt + ... Команды

Используются вместе с другими клавишами для выполнения команд.

8. Что такое курсор?

При вводе текста компьютер должен показывать, где появится следующий символ. Для этого используется курсор.

Например:

Сегодня мы изучаем информатику

Вертикальная мигающая черта показывает место, куда будет введён следующий символ.

Практическая работа

«Ввод и редактирование текста с помощью клавиатуры»

  1. Запусти текстовый редактор.
  2. Введи предложенный учителем текст с помощью клавиатуры.
  3. Используй Space для разделения слов.
  4. Используй Enter для перехода на новую строку.
  5. Попробуй исправить ошибку с помощью Backspace.
  6. Удали символ справа от курсора с помощью Delete.
  7. Используй Shift для ввода заглавной буквы.
  8. Включи и выключи режим заглавных букв с помощью Caps Lock.
  9. Перемещай курсор по тексту с помощью стрелок.
  10. Исправь несколько специально допущенных ошибок в тексте.
💡 Важно: клавиатура вводит информацию в компьютер. Она не предназначена для хранения информации.

Главное, что нужно запомнить

  • Ввод информации — это передача данных в компьютер.
  • Клавиатура — одно из основных устройств ввода информации.
  • С помощью клавиатуры можно вводить буквы, цифры и различные символы.
  • Клавиши делятся на несколько основных групп: буквенно-цифровые, функциональные, управляющие, клавиши перемещения и цифровой блок.
  • Backspace удаляет символ слева от курсора, а Delete — справа.
  • Space создаёт пробел, а Enter позволяет перейти на новую строку.
  • Shift используется для отдельных заглавных букв, а Caps Lock включает режим постоянного ввода заглавных букв.
  • Ввод, обработка и хранение информации — разные процессы.
