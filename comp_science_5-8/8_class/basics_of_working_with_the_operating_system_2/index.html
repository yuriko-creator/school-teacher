01 · Знакомимся с объектами

Что находится внутри графической ОС?

В графической операционной системе информация и доступные действия представлены в виде объектов. У каждого объекта своё назначение и свой набор возможных действий.

📄

Файл

Именованная совокупность данных. Файл может содержать текст, изображение, музыку, видео, программу и другие данные.

данные
📁

Папка

Помогает организовать хранение файлов и других папок, чтобы нужную информацию было проще найти.

организация
💻

Программа

Предназначена для выполнения определённых задач: работы с текстом, изображениями, сайтами и другими данными.

действие
🔗

Ярлык

Ссылка на другой объект. Позволяет быстро перейти к программе, файлу или папке.

быстрый доступ
02 · Файлы

У файла есть имя

Файл — это именованная совокупность данных, которая хранится на носителе информации. Имя помогает человеку найти файл, а расширение — определить его тип.

Например, компьютер может хранить текстовые документы, изображения, музыку, видео и программы. Все они представлены файлами, но могут иметь разные расширения.

.txt .docx .png .jpg .mp3
📄
report .docx
report Имя файла.
.docx Расширение файла.
03 · Папки

Информации нужен порядок

Папки позволяют объединять связанные файлы. При этом одна папка может находиться внутри другой, образуя понятную структуру хранения данных.

💻 Компьютер система
└─ 📁 Документы папка
└─ 📁 Учёба папка
├─ 📁 Информатика папка
│  └─ 📄 домашняя_работа.docx файл
└─ 📁 Математика папка
04 · Программы и ярлыки

Ярлык — не сама программа

Ярлык содержит ссылку на другой объект и используется для быстрого доступа. Поэтому удаление ярлыка обычно не удаляет программу, файл или папку, на которые он указывает.

08 · Не перепутай

Копирование ≠ перемещение

Эти операции похожи тем, что объект появляется в другом месте. Но результат у них различается.

📋 Копирование

Исходный объект остаётся на прежнем месте, а в другом месте появляется его копия.

📁 Папка A
📄 доклад.docx
⟶
📁 Папка B
📄 доклад.docx
Результат: файл находится и в папке A, и в папке B.

📦 Перемещение

Объект меняет своё расположение: в старом месте его больше нет.

📁 Папка A
файл перемещён
⟶
📁 Папка B
📄 доклад.docx
Результат: файл теперь находится только в папке B.
