01

Вспомним: алгоритм, команда, исполнитель

Эти понятия помогут понять новую тему.

Алгоритм — понятная исполнителю последовательность точных команд, направленная на решение задачи.
📝

Команда

Указание, какое конкретное действие нужно выполнить.

🤖

Исполнитель

Человек, устройство или программа, которые выполняют команды.

🎯

Результат

То, что мы получаем после правильного выполнения алгоритма.

Команды должны быть понятными исполнителю, а порядок их выполнения — определённым. Например, Робот умеет двигаться по клеткам, но не может выполнить команду «Сделай красиво», потому что она недостаточно точная.

02

Что такое линейный алгоритм?

Один путь выполнения — команда за командой.

Линейный алгоритм — алгоритм, в котором команды выполняются последовательно, одна за другой, без ветвлений и циклов.
Шаг 1 → Шаг 2 → Шаг 3 → Результат ✓
1️⃣

По порядку

После одной команды выполняется следующая.

🚫

Без выбора

Не нужно выбирать между двумя вариантами действий.

➡️

Без цикла

Нет команды, которая возвращает выполнение к предыдущим шагам.

💡 Важно: если поменять шаги местами, результат может измениться. Даже правильные команды не помогут, если выполнить их в неправильном порядке.
03

Линейный алгоритм в математике

Сначала сложение, затем умножение.

Вычислим значение выражения (5 + 3) × 2. Для этого достаточно выполнить несколько действий в нужном порядке.

5 + 3 = 8 1. Сложить числа
8 × 2 = 16 2. Умножить результат
Ответ: 16 3. Записать результат

Каждый шаг здесь выполняется один раз, по порядку, без выбора и повторения. Поэтому алгоритм линейный.

🔎 Подумай: если сначала умножить 3 на 2, а затем прибавить 5, получится 11, а не 16. Значит, менять порядок шагов нельзя.

🔷 Блок-схема линейного алгоритма

Блок-схема — графическое представление алгоритма. Овал обозначает начало или конец, прямоугольник — действие, а стрелки показывают последовательность выполнения.

05

Линейные алгоритмы вокруг нас

Их можно встретить не только в компьютере.

🎒

Собираем портфель

1. Открыть рюкзак.
2. Положить учебники.
3. Положить тетради и пенал.
4. Закрыть рюкзак.

💻

Работаем на компьютере

1. Включить компьютер.
2. Дождаться загрузки.
3. Открыть нужную программу.
4. Создать новый документ.

Алгоритмы могут отличаться количеством шагов, но линейные алгоритмы объединяет одно: заданные команды выполняются последовательно . Например, нельзя сначала закрыть портфель, а затем положить туда учебники, не открывая его снова.

Попробуй мысленно заменить исполнителя: человек может догадаться, что нужно открыть рюкзак, а формальному исполнителю необходимо дать точную команду.
06

Робот выполняет команды по порядку

Четыре шага — один маршрут до финиша.

Представим Робота, который умеет перемещаться по клетчатому полю. Его система команд: ↑ вверх, ↓ вниз, ← влево, → вправо . Каждая команда перемещает его на одну клетку.

Робот начинает движение из клетки (строка 4, столбец 1).

После двух команд «Вправо» он находится в клетке (4, 3). Затем дважды поднимается вверх и достигает финиша — клетки (2, 3).

Почему алгоритм линейный? Робот не выбирает дорогу самостоятельно. Он просто выполняет четыре команды в заданном порядке.
07

Как проверить алгоритм и найти ошибку?

Проверяем каждый шаг, а не только итог.

✅ Правильная последовательность

Для выражения (5 + 3) × 2 сначала вычисляем сумму, затем умножаем её на 2. Получаем 16.

⚠️ Изменённый порядок

Если сначала вычислить 3 × 2, а затем прибавить 5, получится 11. Это уже другая последовательность действий.

08

Главное за урок

Три идеи, которые стоит запомнить.

1. Линейный алгоритм — последовательность команд без ветвлений и циклов.

2. Алгоритм можно записать словами, командами или показать в виде блок-схемы.

3. Порядок команд важен: чтобы проверить алгоритм, нужно пройти все шаги и оценить результат.

Домашнее задание: придумай линейный алгоритм из 5–7 команд для одного повседневного действия. Запиши команды по порядку и укажи исполнителя.
