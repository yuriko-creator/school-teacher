Цель урока

Научиться понимать основные объекты операционной системы, знать их назначение и выполнять простейшие действия с файлами и папками.

1

Что такое объект операционной системы?

Во время работы с компьютером мы постоянно взаимодействуем с различными элементами системы. Такие элементы можно рассматривать как объекты операционной системы.

📄

Файл

Объект, в котором хранится определённая информация: текст, фотография, музыка, программа и т. д.

📁

Папка

Объект для организации и хранения файлов и других папок.

↗️

Ярлык

Специальный объект, который позволяет быстро обратиться к другому объекту.

🪟

Окно

Область интерфейса, через которую пользователь взаимодействует с программой или объектом.

2

Файлы

Файл — это объект, предназначенный для хранения информации на компьютере.

📄

Имя файла

Позволяет отличать один файл от другого. Например:

Мой_рисунок.png
🏷️

Тип файла

Обычно определяется расширением и указывает на формат содержащейся информации.

.txt — текстовый файл
.jpg — изображение
.mp3 — аудиофайл
3

Папки

Папки помогают организовать файлы так, чтобы нужную информацию было проще найти.

📁

Папка

В папке можно хранить файлы и другие папки.

📁 Школа
└── 📁 Информатика
    └── 📄 Урок.txt
🗂️

Вложенная папка

Папка, находящаяся внутри другой папки. Это позволяет создавать удобную структуру хранения.

Папки можно объединять в несколько уровней.
4

Ярлыки

📁

Ярлык — это быстрый путь к объекту

Ярлык не является копией самого файла или папки. Он позволяет быстро открыть объект, к которому он относится.

Поэтому удаление ярлыка не означает удаление исходного объекта.

5

Окна

Окно — один из основных элементов графического интерфейса. Через окна пользователь взаимодействует с программами, файлами и папками.

Проводник
📁 Открыть
➖ Свернуть
⬜ Развернуть
✕ Закрыть

Размер и положение окна можно изменять, а между несколькими открытыми окнами можно переключаться.

7

Практическая работа

Выполни последовательность действий с файлами и папками.

  1. Создай новую папку с названием Информатика.
  2. Внутри неё создай папку Урок.
  3. Переименуй папку Урок, например, в Мой урок.
  4. Создай или сохрани любой небольшой файл в папке Мой урок.
  5. Скопируй файл в другую папку.
  6. Перемести исходный файл в другое место.
  7. Удали один из созданных объектов.
  8. Открой корзину и при необходимости восстанови удалённый объект.
⚠️ Для практической работы используй только учебные файлы и папки, чтобы случайно не изменить важные данные.

Итог урока

Операционная система работает с различными объектами. Основные из них — файлы, папки, ярлыки и окна. Файлы хранят информацию, папки помогают её организовывать, ярлыки обеспечивают быстрый доступ к объектам, а окна позволяют взаимодействовать с программами и данными.

С объектами можно создавать, открывать, выбирать, копировать, перемещать, переименовывать, удалять и восстанавливать их.
