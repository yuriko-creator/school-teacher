02 · Устройство компьютера

Язык из двух символов

Мы привыкли использовать десять цифр: от 0 до 9. А для двоичной записи достаточно только двух — 0 и 1.

Почему именно два состояния?

Электронные схемы компьютера могут различать два состояния сигнала. Для простоты представим их как выключенную и включённую лампочку.

выключено

1

включено

В настоящих микросхемах используются электрические сигналы, а не лампочки. Но принцип похож: два хорошо различимых состояния удобно и надёжно использовать для записи и обработки информации.

Восемь бит дают 256 различных комбинаций: от 00000000 до 11111111.

Обрати внимание

Не всякая комбинация из восьми бит обозначает букву. Байт может представлять число, часть изображения, элемент звука, часть текстового символа и многое другое. Значение зависит от способа использования данных.

04 · Текстовая информация

Как буква превращается в нули и единицы?

Компьютер хранит текст не как написанные от руки буквы. Каждому символу соответствует определённый числовой код, который можно представить в двоичном виде.

Шаг 1. Символ A
→
Шаг 2. Числовой код ASCII 65
→
Шаг 3. Двоичная запись байта 01000001
Разберём пример

Заглавной латинской букве A в таблице ASCII соответствует число 65. Его двоичная запись — 1000001.

Для записи в виде полного байта добавим ноль слева: 01000001.

Таким образом, одна буква представлена последовательностью из восьми бит.

Из чего состоит текст?

Текст — это последовательность символов. Символами являются не только буквы, но и цифры, знаки препинания, специальные знаки и пробелы.

А Буква
7 Цифра
! Знак
␣ Пробел
? Знак

Например, в сообщении «Привет!» компьютер должен представить каждый символ, включая восклицательный знак.

05 · Правила кодирования

ASCII и Unicode

Как компьютер узнаёт, что число 65 означает букву A? Для этого существуют специальные стандарты, определяющие соответствие между символами и их кодами.

Таблица кодировки символов

Это таблица, в которой каждому символу соответствует определённый числовой код.

Когда компьютер читает текст, он использует сведения о кодировке, чтобы правильно восстановить символы из данных.

ASCII

Один из первых широко известных стандартов

ASCII позволяет представлять латинские буквы, цифры, некоторые знаки препинания и управляющие символы.

  • Содержит 128 кодовых значений: от 0 до 127.
  • Использует для каждого кода 7 двоичных разрядов; часто записывается с помощью байта.
  • Не включает русские буквы.
  • Подходит для простых текстов на латинице.
Unicode

Символы множества языков мира

Unicode позволяет задавать коды для огромного количества символов из разных языков, а также математических знаков и эмодзи.

  • Включает латинские и кириллические буквы.
  • Поддерживает множество письменностей мира.
  • Содержит символы и графические знаки.
  • Для хранения может использоваться кодировка UTF-8.
Важное различие

Unicode устанавливает, какой номер соответствует символу. А UTF-8 определяет, как записать этот номер в виде последовательности байтов.

Например, латинская буква A занимает в UTF-8 один байт, а русская буква А — два байта. Это не одинаковые символы, хотя они похожи внешне.

Небольшой фрагмент таблицы ASCII

Символ Десятичный код Двоичная запись (8 бит)
A 65 01000001
B 66 01000010
C 67 01000011
a 97 01100001
1 49 00110001
Пробел 32 00100000
! 33 00100001

Таблица показывает лишь несколько символов. В обычной таблице ASCII также содержатся другие буквы, цифры, знаки и управляющие коды.

Преврати текст в двоичный код

Теперь попробуем закодировать настоящее сообщение. Введи любое слово или короткую фразу, и программа покажет байты UTF-8, из которых состоит её цифровая запись.

Кодировщик сообщений

Начни с простого слова ABC. Затем попробуй написать слово на русском языке и сравни результаты.

Символов Unicode 3

> UTF-8 BINARY OUTPUT 
01000001 01000010 01000011

Латинские буквы ABC занимают по одному байту в UTF-8.

Что нужно заметить?

В кодировке UTF-8 простая латинская буква обычно занимает 1 байт, русская буква — обычно 2 байта, а многие эмодзи — 4 байта.

Поэтому число символов в тексте не всегда совпадает с количеством байтов, необходимых для его хранения.

А как получить текст обратно?

Нужно выполнить обратное действие: прочитать числовые значения байтов и определить по таблице кодировки, какие символы им соответствуют.

Этот процесс называется декодированием.

08 · Проверь себя

Секретное сообщение

Перед тобой последовательность из двух байтов. Попробуй определить, какое слово из латинских букв в ней зашифровано.

Интерактивная лаборатория №3

Декодирование двоичного сообщения

01001000 01001001

Подсказка: первый байт равен числу 72, а второй — 73. Найди соответствующие латинские буквы.

HI

01001000 = 72 = H

01001001 = 73 = I

Получилось английское приветствие HI!

Почему иногда вместо букв появляются странные символы?

Такое может происходить, если программа неправильно определила кодировку текстовых данных.

Например, байты текста были записаны в одной кодировке, а прочитаны по правилам другой. В результате символы отображаются неправильно.
